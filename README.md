# 引っ越し費用まとめ帳

引っ越しにかかる賃貸初期費用・引っ越し業者費用・家具家電費用などをまとめて管理するWebサービスです。自分で調べた金額や参考概算を入力し、総額・カテゴリ別の内訳・予算との差を確認できます。

会員登録なしで費用計算を試せます。登録後は複数の費用リストを保存・更新し、物件や引っ越し条件ごとの比較に利用できます。

## 開発背景と想定ユーザー

引っ越し費用を調べた際、具体的な金額を知る前に氏名・電話番号・住所などの入力を求められ、「まずは費用感だけ知りたい」という段階で気軽に確認しづらいと感じたことが開発のきっかけです。また、業者費用だけでは必要な予算を把握できず、敷金・礼金・家具家電などの出費もまとめて整理する必要がありました。

主に、進学・就職・転職・住み替えなどで引っ越しを検討している20〜30代の人を想定しています。業者への見積もり依頼や物件契約の前に予算を整理し、正式な金額が分かった後も同じリストを更新しながら準備を進められることを目指しています。

このサービスでは業者への見積もり依頼は行いません。ユーザー自身が集めた費用情報と参考概算を一か所にまとめ、予算判断に使えることを提供価値としています。

## 実装済みの機能

### ゲスト利用・費用リスト管理

- 会員登録なしで費用を入力し、計算結果を確認できます。
- ログイン後は、費用リストの保存・閲覧・編集・削除ができます。
- リスト名・予算・判断メモを設定できます。リスト名は保存時に未入力の場合、「引っ越し費用リスト」になります。
- マイページで保存済みリストを一覧表示し、リスト名を変更できます。
- 保存前の費用データはPostgreSQLに一時保持し、セッションには識別用トークンだけを保存します。

### 費用項目の入力・状態管理

費用項目はカテゴリごとに追加・削除でき、候補からの選択に加えて自由な費用名も入力できます。

| カテゴリ | 費用名の候補例 |
| --- | --- |
| 賃貸費用 | 家賃、敷金、礼金、仲介手数料、前家賃、火災保険料 |
| 引っ越し業者費用 | 引っ越し業者費用、その他引っ越し費用 |
| 家具家電費用 | 洗濯機、冷蔵庫、テレビ、電子レンジ、炊飯器、掃除機 |
| その他費用 | 交通費、手続き費用、雑費 |

各項目には、金額とは別に次の状態を設定できます。金額が分からない項目は空欄のまま保存できます。

| 状態 | 用途 |
| --- | --- |
| 未確認 | 金額の確認が済んでいない項目を管理する |
| 概算 | 自分で入力した仮の金額や、サービスの参考概算を管理する |
| 確定 | 見積書や契約内容などで確認した金額を管理する |

保存済みリストでは、費用の編集に加えて、詳細画面の内訳から状態だけを更新できます。

### 総額・予算比較・内訳グラフ

- 費用合計と4カテゴリの内訳を表示します。
- 予算を入力すると、残額または超過額を表示します。
- 予算の入力や超過の有無にかかわらず、未確認項目の件数と確認案内を表示します。予算超過時は概算項目の有無に応じた案内と、合計金額が最も大きいカテゴリも提示します。
- Chart.jsの円グラフでカテゴリ別の費用割合を表示します。1円以上の概算項目を含む場合は、金額が変わる可能性を案内します。

合計・カテゴリ集計には、状態にかかわらず入力済みの金額を含め、金額の空欄は0円として扱います。予算が空欄の場合は予算比較を行いません。

結果・詳細画面の内訳には、金額が空欄・0円の項目も表示します。空欄は「金額未入力」、0円は「0円」と区別し、金額未入力の項目があれば表示中の合計が最終総額ではないことを案内します。

費用名が空欄で金額だけ入力されている行は、計算前に該当カテゴリ・行番号とエラーを表示します。費用名・金額が両方空欄の追加行は無視し、費用名だけ入力した行は計算・保存できます。保存に失敗した場合も入力を保持し、具体的な原因を表示します。

### 参考概算の入力補助

金額が空欄の項目で「概算」を選ぶと、費用名に応じて次の入力補助を利用できます。

- 賃貸初期費用の家賃以外の候補項目には、入力済みの家賃と同額を仮入力します。
- 家具家電には費用名ごとの固定参考額を使います。その他引っ越し費用・その他費用などにはカテゴリの固定参考額を使います。
- 「引っ越し業者費用」は、出発地・到着地の郵便番号または住所を入力し、「距離から概算する」を押すと、Google Routes APIで取得した道路距離から算出します。
- 自由入力した候補外の費用名には参考額を自動入力せず、手入力を案内します。

引っ越し業者費用の計算ルールは次のとおりです。

| 道路距離 | 参考概算 |
| --- | --- |
| 50km未満 | 30,000円 |
| 50km以上200km未満 | 50,000円 |
| 200km以上500km未満 | 100,000円 |
| 500km以上 | 150,000円 |

概算は正式な見積もりではありません。現在の計算は距離帯に応じた固定額で、荷物量・時期・業者ごとの料金は反映しません。郵便番号だけで計算した距離は該当地域付近を基準とする参考値です。正式な金額が分かったら、金額と状態を更新できます。

### 複数リストの比較

物件や条件ごとに費用リストを保存し、マイページから2件を選んで比較できます。比較画面では総額の差額、各リストの予算・予算との差、カテゴリ別合計を表示します。

### 認証・アカウント管理

- 名前・メールアドレス・パスワードによる会員登録、ログイン・ログアウト
- Googleアカウントによる新規登録・ログイン
- メールによるパスワード再設定（リンクの有効期限は2時間、再送間隔は5分）
- 現在のパスワードを確認したうえでのメールアドレス変更
- 退会確認画面からのアカウント削除（ユーザー情報・Google連携情報・保存済みの費用リストと項目を削除）

Googleのみで登録したアカウントは、メールアドレス変更とパスワード再設定の対象外です。また、既存のメール登録アカウントと同じメールアドレスのGoogleアカウントを、自動的に連携する機能はありません。

## 利用の流れ

1. トップページから費用入力画面を開き、予算・費用名・金額・状態を入力します。
2. 必要に応じて項目を追加・削除し、参考概算を使って「計算する」を押します。
3. 結果画面で総額・予算との差・内訳グラフを確認し、リスト名や判断メモを入力します。
4. ログイン済みの場合は「内容を保存する」で保存します。未ログインの場合は、ログイン画面へ進み、新規会員登録またはログインを行います。
5. マイページから保存済みリストを開き、金額・状態・メモを更新します。複数の候補がある場合は2件を選んで比較します。

新規会員登録時（メール・Google）は、一時保持された費用データの保存を試みます。既存アカウントでのログイン後は、保存待ちの入力がある場合に計算結果画面へ戻り、保存操作を行えます。入力がなければマイページへ移動します。
